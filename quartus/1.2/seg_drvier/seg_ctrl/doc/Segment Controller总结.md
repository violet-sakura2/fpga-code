## 1 基础语法与连线规范

```verilog
wire tick_50ms = (cnt_50ms == CNT_50MS - 1);[^1]
```

定义一根叫 tick_50ms 的信号线，它的值实时地等于“计数器是否数到了 CNT_50MS - 1”这个比较结果。数到了就是 1，没数到就是 0。

### 1.1 常见运算符与表达式

`<<` 是左移运算符，左移 n 位相当于乘以 2^n：

```
a << n = a × 2^n
```

```verilog
assign data_out = data_in << shift_amt;
```

把输入数据 data_in 向左移动 shift_amt 位，移位结果连续赋值给输出 data_out。

它实现的是一个组合逻辑的可变左移器。

```verilog
assign data1 = data % 1000 / 100;
```

- `%` 是取模/求余数
- `/` 是除法；如果两边都是整数，就是整数除法，小数部分直接丢掉
- `%` 和 `/` 优先级相同，并且从左到右结合

所以它等价于：

```verilog
assign data1 = (data % 1000) / 100;[^2]
```

这个表达式的实际含义是：取出 data 的百位数字，结果范围一般是 0~9。

不过更直观的写法通常是：

```verilog
assign data1 = (data / 100) % 10;[^3]
```

### 1.2 常量声明

`localparam` 是 Verilog 中的局部常量：

```verilog
parameter  NUM_STATES = 4;   // 全局参数，可以被实例化时覆盖
localparam IDLE       = 1 << 0;   // 只能在模块内部使用，不能被外部覆盖
```

```verilog
`timescale 1ns/100ps
```

`` ` `` 表示“这是编译器指令”，`timescale 1ns/100ps` 表示“时间单位 1ns，时间精度 100ps”。

### 1.3 信号类型：wire 与 reg

counter_seg 里的 clk_200hz、clk_10hz、counter 虽然“有值”，但它们不是被 always 块赋值的，而是被子模块的输出端口驱动的，所以必须用 wire，不能用 reg。

- **wire（线网）**：用于连线。被 assign 赋值、或被子模块输出端口驱动的信号，必须是 wire。
- **reg（寄存器）**：用于存储。在 always 或 initial 块中被赋值的信号，必须声明为 reg。

端口方向限制：

| 端口   | 允许类型            | 说明                                                            |
| ------ | ------------------- | --------------------------------------------------------------- |
| input  | 只能是 wire（默认） | 输入端口不能是 reg，因为输入由外部驱动                          |
| output | 可以是 wire 或 reg  | 如果内部用 assign 驱动，用 wire；如果内部用 always 驱动，用 reg |
| inout  | 只能是 wire         | 双向端口                                                        |

> **避坑**：reg 类型不能由模块输出端口连续驱动。例如，连接子模块输出的中间信号（如 counter）必须用 wire。

### 1.4 阻塞赋值与非阻塞赋值

- 时序逻辑（`always @(posedge clk)`）必须用非阻塞赋值 `<=`。
- 组合逻辑（`always @(*)`）必须用阻塞赋值 `=`。
- 绝不能在同一个 always 块中混用两者。

## 2 状态机与编码方式

### 2.1 有限状态机（FSM）

状态机（State Machine）是一种用来描述“一个对象在生命周期中有哪些状态、在什么条件下从一个状态切换到另一个状态”的模型。它把复杂逻辑拆成有限个状态和状态之间的转换规则。

1. **有限状态机 FSM**：状态数量有限，最常用
2. **确定性/非确定性状态机**：给定状态和事件，下一状态是否唯一
3. **Moore 型/Mealy 型**：输出只取决于状态，或取决于状态+输入
4. **层次状态机**：状态里还能嵌套子状态，适合复杂系统

### 2.2 One-hot 编码（独热编码）

在状态机里，指的是一种用“一位比特对应一个状态”的编码方式。它的核心特点是：在任意时刻，状态寄存器中只有一位是“热”的（为 1），其余所有位都是 0。

## 3 模块化与参数化设计

### 3.1 模块例化与层次化设计

adder_array 内部之所以能“放” adder，是因为 Verilog 允许在一个模块内部实例化另一个模块。这叫模块例化，也叫层次化设计。

- adder_array 这个模块的功能，是由若干个 adder 实例共同完成的。
- adder_array 是整体，adder 是组成部分。

#### 3.1.1 复用性

：不用重复写加法逻辑

如果没有 adder 模块，adder_array 里要写 4 遍加法：

```verilog
module adder_array (...);
    assign sum[7:0]   = a[7:0]   + b[7:0];
    assign sum[15:8]  = a[15:8]  + b[15:8];
    assign sum[23:16] = a[23:16] + b[23:16];
    assign sum[31:24] = a[31:24] + b[31:24];
endmodule
```

有了 adder 模块，只需要例化 4 次：

```verilog
module adder_array #(
    parameter WIDTH = 4
)[^4] (...);
    genvar i;[^5]
    generate
        for (i = 0; i < NUM_ADDERS; i = i + 1) begin : adder_gen[^6]
            adder #(WIDTH)[^7] adder_inst (
                .a   (a[i*WIDTH +: WIDTH]),
                .b   (b[i*WIDTH +: WIDTH]),
                .sum (sum[i*WIDTH +: WIDTH])
            );
        end
    endgenerate
endmodule
```

#### 3.1.2 可维护性

如果加法器逻辑要改（比如加流水线），只改 adder 模块：

```verilog
module adder #(parameter WIDTH = 4)(...);
    // 修改这里
endmodule
```

### 3.2 参数化：同一个 adder 可以变成不同位宽

```verilog
adder #(8)  adder_inst0 (...);   // 8 位加法器
adder #(16) adder_inst1 (...);   // 16 位加法器
adder #(32) adder_inst2 (...);   // 32 位加法器
```

### 3.3 generate 语句

**作用**：在“展开阶段”（elaboration）根据参数或条件，动态生成硬件结构或模块实例。

常用于参数化模块阵列的批量例化（如 `generate for` 循环）。

## 4 FIFO 与存储管理

FIFO 是 First In First Out 的缩写，中文叫先进先出存储器，也叫先进先出队列。

| 类型      | 说明                                   |
| --------- | -------------------------------------- |
| 同步 FIFO | 读写用同一个时钟 clk                   |
| 异步 FIFO | 写用 wr_clk，读用 rd_clk，两个时钟不同 |

异步 FIFO 常用于跨时钟域数据传输，设计更复杂，需要格雷码指针等。

### 4.1 FIFO 内部结构

- **存储阵列**[^8]：真正存数据的地方，深度 DEPTH，位宽 DATA_WIDTH；
- **写指针**：指向下一个要写入的位置；
- **读指针**：指向下一个要读出的位置；
- **写控制**：根据 wr_en 和 full 决定是否写入；
- **读控制**：根据 rd_en 和 empty 决定是否读出。

### 4.2 $clog2 系统函数

全称是 ceiling log2，意思是：计算以 2 为底的对数，然后向上取整。返回最小整数 k，使得 2^k ≥ n。

数学表达：

```
$clog2(n) = ⌈log2(n)⌉        // 其中 ⌈ ⌉ 表示向上取整。
```

**应用**：在数字设计中，经常需要根据“深度”计算“地址位宽”。

FIFO 深度是 10，需要多少位地址？

```
log2(10) ≈ 3.32
⌈3.32⌉ = 4
```

```verilog
// 用 $clog2 根据 DEPTH 自动计算地址位宽
localparam ADDR_WIDTH = $clog2(DEPTH);

// 存储阵列：深度 DEPTH，位宽 DATA_WIDTH
reg [DATA_WIDTH-1:0] mem[^9] [0:DEPTH-1];

// 写指针：ADDR_WIDTH 位
reg [ADDR_WIDTH-1:0] wr_ptr;

// 读指针：ADDR_WIDTH 位
reg [ADDR_WIDTH-1:0] rd_ptr;
```

**小深度时：综合成寄存器**

如果 DEPTH 很小（比如 16），综合工具可能生成：

- 16 个 8 位寄存器
- 写译码器
- 读多路选择器

**大深度时：综合成 RAM**

如果 DEPTH 很大（比如 1024），综合工具通常生成：

- Block RAM（FPGA）或 SRAM（ASIC）

所以：

```verilog
reg [DATA_WIDTH-1:0] mem [0:DEPTH-1];
```

既可以综合成寄存器阵列，也可以综合成 RAM，取决于深度和综合工具的策略。

## 5 三态控制与总线时序

### 5.1 三态控制/INOUT

“三态控制”是一个源于数字电路的经典概念，核心在于让一条信号线拥有逻辑“0”、逻辑“1”之外的第三种状态——高阻态（High-Z）。

普通电路输出只有 0 或 1。而“三态门”电路多了一个使能端（EN 或 OE），就像总开关：

- **EN 有效时**：电路正常输出 0 或 1。
- **EN 无效时**：输出端与内部电路断开，呈高阻态，相当于“隐身”了，对总线上的信号不产生任何影响。

### 5.2 总线切换时间

外部设备并不能立刻往里塞数据，从 50ns 到真正输入第一个有效数据 din_0 之间，有一个等待缓冲期。在时序图里，仿真软件往往会把“总线释放等待时间”和“第一个数据 din_0”合并画成一个更宽的方块

0ns 刚复位/启动时：是一个被标注为“当前无效”的总线初始数据块。

## 6 项目实战避坑指南（补充总结）

### 6.1 数码管驱动方式对比

- **动态扫描（hex8）**：需高频（1kHz）轮流点亮，利用视觉暂留。
- **静态驱动（74HC595）**：串行输入、并行锁存。数据发送完毕后无需 FPGA 持续刷新，自带锁存功能。

### 6.2 74HC595 硬件调试踩坑

- **极性相反**：若显示为乱码或反色，查表段码需按位取反。
- **左右颠倒**：595 级联顺序问题，调整顶层拼接顺序（如 `{seg_units, seg_tens}`）。
- **跑得太快**：
  1. 修改时钟分频模块中的计数上限（如将分频上限加大）。参考 `counter_99.v`。
     也叫“时钟使能法”：保持全局时钟统一，用计数器产生一个 tick（脉冲使能）信号：
     ```verilog
     wire tick = (div_cnt == 4'd9);
     if (tick) begin ... end
     ```
  2. 降低驱动时钟频率（如 10Hz 降至 1Hz）。参考 `clk_gen.v`。

```Verilog
adder_gen[0].adder_inst
```

       实例化时写就把 WIDTH 覆盖成 8。

