## 1 项目概述

本次项目基于 Altera Cyclone IV（EP4CE10）开发板，完成了从环境搭建、Verilog 源文件编写、Testbench 仿真到上板烧录的全流程验证。实现了通过按键（Key）控制 LED 灯亮灭的功能。

---

## 2 核心知识点提炼

### 2.1 规范的工程目录结构

| 目录    | 说明                                                                                                |
| ------- | --------------------------------------------------------------------------------------------------- |
| `rtl` | 存放项目的 RTL 代码。这是项目的核心，文件名与 module 名称应当一致。                                 |
| `par` | 存放综合和布局布线文件，主要是 Quartus 工程文件（`.sof`[^1]、`.qsf`[^2]）及编译生成的中间文件。 |
| `sim` | 存放 Testbench 仿真文件和波形文件。                                                                 |
| `doc` | 存放项目相关的文档，包括该项目用到的 datasheet、芯片规格书（specification）等。                     |

### 2.2 源代码设计

#### 2.2.1 两种基本逻辑

- **组合逻辑**：用 `assign`[^3] 连续赋值（如 `assign led_0 = (key_0 == 0) ? 1 : 0;`[^4]），被赋值对象必须是 `wire` 类型。
- **时序逻辑**：用 `always`[^5] `@(posedge clk)` 块，被赋值对象必须是 `reg` 类型。

#### 2.2.2 赋值符号

- 组合逻辑用阻塞赋值 `=`。
- 时序逻辑用非阻塞赋值 `<=`。

## 3 问题和经验

报错 `unexpected endmodule` 可能是前面的 `always` 块漏了 `begin...end`，或者把 `wire` 类型放进了 `always` 块里用 `<=` 赋值。

## 4 小结

### 4.1 代码规范

- 每个 `.v` 文件头部必须有注释声明（作者、日期、功能描述）。PS：正式情况下应严格执行。
- 注释不要写废话（如 `cnt = cnt + 1; // 加1`），要写目的（如 `// 用于分频计数`）。
- 代码对齐要整齐，`begin` 推荐跟在条件判断同行（如 `if (a) begin`），提高可读性。

### 4.2 语法学习

#### 4.2.1 设计建模的描述方式

- **结构化描述**：例化门电路或子模块，描述连接关系。
- **数据流描述**：用 `assign` 连续赋值描述信号间逻辑关系。
- **行为描述**：用 `always` / `initial` 过程块描述算法或状态变化。
  1. `initial` 语句：此语句只执行一次。
  2. `always` 语句：此语句总是循环执行，或者说此语句重复执行。

#### 4.2.2 两类数据类型

- **线网类型（`wire`）**：构件间的物理连线。
- **寄存器类型（`reg`）**：抽象的数据存储元件。

#### 4.2.3 Verilog 语言要素

- 以 `$` 字符开始的标识符表示系统任务或系统函数。
- 以反引号（`` ` ``）开始的某些标识符是编译器指令。
- `` `define `` 指令用于文本替换，`` `undef `` 指令取消前面定义的宏。

#### 4.2.4 参数

参数是一个常量。参数经常用于定义时延和变量的宽度。使用参数说明的参数只被赋值一次。

参数值也可以在编译时被改变。改变参数值可以使用参数定义语句，或通过在模块初始化语句中定义参数值（这两种机制将在第 9 章中详细讲解）。

#### 4.2.5 模块声明

- **非 ANSI 风格模块声明**：先在 `module` 的括号里只写端口名，再在下面逐个用 `input`、`output` 声明方向和类型。PS：功能完全没问题，只是比较啰嗦。

```verilog
module led_twinkle(
    Clk,
    Reset_n,
    Led
);
    input Clk;
    input Reset_n;
    output reg Led;
```

- **ANSI 风格**：把方向和类型直接写进端口列表。

```verilog
module led_twinkle(
    input      Clk,
    input      Reset_n,
    output reg Led
);
```

## 附录：Verilog 代码规范速查
